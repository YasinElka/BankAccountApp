# BankAccountApp

A simple C# Windows Forms application for managing bank accounts.

## About the Project

BankAccountApp is a desktop application developed in C# using Windows Forms.

The application demonstrates basic object-oriented programming concepts such as classes, inheritance, methods, and encapsulation.

## Features

- Create and manage bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Support for savings accounts
- Calculate interest for savings accounts
- Simple Windows Forms user interface

## Technologies

- C#
- .NET
- Windows Forms
- Object-Oriented Programming
- Visual Studio
- Git & GitHub

## Main Classes

### BankAccount.cs

Contains the main bank account functionality, including balance management, deposits, and withdrawals.

### SavingsAccount.cs

Represents a savings account and extends the functionality of the bank account with savings-related functionality.

### Form1.cs

Contains the main Windows Forms application logic and user interaction.

### Program.cs

Contains the entry point of the application.

## How to Run

1. Clone the repository.
2. Open `BankAccountApp.sln` in Visual Studio.
3. Build the solution.
4. Run the application.

## Purpose

This project was created as a learning project to practice C# programming, object-oriented programming, Windows Forms, and Git/GitHub version control.
